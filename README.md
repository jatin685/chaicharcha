# Chai & Charcha Cafe & Roastery - Customer Loyalty & Rewards Management System
A mobile-friendly web prototype for an Indian cafe loyalty programme (PCTE interdisciplinary MBA + BCA project).

**How to run:** keep all files in one folder and open `index.html` in a browser.

Files: `index.html`, `style.css`, `data.js`, `app.js`. See `PROJECT_GUIDE.md` for details.
